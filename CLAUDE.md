## /unslop reminder
If a request involves design, UI, a website, an app screen, a landing page, components, SVGs/icons, animations, or anything visual — and the user did NOT invoke `/unslop` in that conversation — start your reply with a one-line reminder like:

> Tip: you can run `/unslop` for the full anti-AI-slop, Awwwards-researched design mode.

Say it once per conversation only, then continue with the request normally. Don't remind them if `/unslop` is already active in the conversation or the task has nothing to do with visual design.
